\# 3. Source Code



Upon full payment of the Contract Price, the Contractor shall deliver:



\- Complete application source code

\- Frontend source code

\- Backend source code

\- API source code

\- Configuration files

\- Project structure



The source code shall be delivered through one of the following methods:



\- GitHub Repository Transfer

\- ZIP Archive

\- Other mutually agreed method



\---



\# 4. Database



The Contractor shall provide:



\- Prisma Schema

\- Database Structure

\- Migration Files (if available)

\- Seed Data (if available)



The Employer shall become the owner of the project database after full payment.



\---



\# 5. Deployment



The Contractor shall complete one (1) initial production deployment including:



\- Build Configuration

\- Environment Setup

\- Domain Configuration

\- SSL Configuration

\- Production Launch



Subsequent deployments requested after project handover may be subject to additional service fees unless otherwise agreed.



\---



\# 6. Domain



If the domain name is registered under the Employer's ownership, the Contractor shall:



\- Configure DNS

\- Connect the website

\- Configure SSL

\- Verify domain functionality



Ownership of the domain name shall remain with the registered owner.



\---



\# 7. Hosting



The Contractor shall assist in:



\- Hosting Configuration

\- Initial Deployment

\- Production Environment Setup



Hosting subscription fees are the responsibility of the Employer unless otherwise specified in writing.



\---



\# 8. Documentation



The Contractor shall provide basic technical documentation including:



\- Project Overview

\- Installation Guide

\- Deployment Guide

\- Environment Variable Template (.env.example)

\- Basic User Guide

\- Administrator Guide



Comprehensive system documentation, architecture diagrams, API documentation, developer manuals, or training materials are excluded unless expressly included in the Agreement.



\---



\# 9. Administrator Account



The Contractor shall create an initial administrator account.



The Employer shall be responsible for changing passwords after receiving the system.



\---



\# 10. Credentials



Upon final payment, the Contractor shall transfer all applicable project credentials that are under the Contractor's control, including:



\- Administrator Account

\- Git Repository Access

\- Domain Access (if managed by Contractor)

\- Hosting Access (if managed by Contractor)

\- Database Access

\- Supabase Project Access

\- Environment Configuration

\- Deployment Instructions



Sensitive credentials shall be transferred securely and separately from the source code repository.



\---



\# 11. Ownership Transfer



Ownership of the following items shall transfer to the Employer only after full payment of the Contract Price:



\- Source Code

\- Database

\- Website Design

\- Project Assets

\- Documentation

\- Configuration Files

\- Custom Software Components



Ownership does not include:



\- Open Source Software

\- Third-party Libraries

\- Commercial Licenses

\- External APIs

\- Cloud Services

\- Frameworks



These remain subject to their respective licenses and terms of use.



\---



\# 12. Warranty Deliverables



The Contractor shall provide bug fixes relating to defects in the delivered software for a warranty period of \*\*90 calendar days\*\* from the date of final acceptance.



The warranty excludes:



\- New Features

\- Design Changes

\- Feature Enhancements

\- Third-party Service Failures

\- Hosting Issues

\- User Misconfiguration

\- Software modified by parties other than the Contractor



\---



\# 13. Acceptance of Deliverables



The Deliverables shall be deemed accepted when:



\- The agreed core modules have been delivered;

\- The platform can be deployed and accessed online;

\- Critical defects preventing normal operation have been resolved; and

\- The Employer has not submitted written objections identifying material non-conformities within \*\*7 calendar days\*\* after delivery.



If the Employer continues to use the delivered system in production after this period without raising material objections in writing, the Deliverables shall be deemed accepted.



\---

\- Content Writing

\- Photography

\- Video Production

\- Data Entry

\- Translation Services

\- Social Media Management

\- Paid API Credits

\- OpenAI Usage Fees

\- Google Maps Usage Fees

\- Cloud Infrastructure Fees

\- Email Service Fees

\- SMS Service Fees



\---



\# 15. Final Project Handover



Upon receipt of full payment, the Contractor shall complete the project handover by transferring all agreed Deliverables and confirming completion in writing.



Thereafter, any maintenance, support, enhancements, or additional development shall be governed by a separate maintenance agreement or new statement of work unless otherwise agreed.
